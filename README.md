# CNN Image Classification using PyTorch

## 📌 Project Overview
This minor project implements a Convolutional Neural Network (CNN) for image classification using Python, PyTorch, and the CIFAR-10 dataset.

## 🎯 Objectives
- Understand CNN architecture.
- Preprocess image data.
- Extract image features using convolutional layers.
- Train a deep learning model for image classification.
- Evaluate the model's performance.

## 🛠️ Technologies Used
- Python
- PyTorch
- Torchvision
- Jupyter Notebook
- CIFAR-10 Dataset

## 🧠 Model Architecture
The CNN model uses convolutional layers, ReLU activation, max pooling, flattening, and fully connected layers to classify images into 10 categories.

## 📊 Dataset
CIFAR-10 contains 60,000 color images across 10 classes:
- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

## ⚙️ Workflow
1. Load the CIFAR-10 dataset.
2. Preprocess and normalize images.
3. Build the CNN model.
4. Train the model.
5. Evaluate model performance.

## ▶️ How to Run
1. Install Python.
2. Install the dependencies:

   `pip install torch torchvision jupyter`

3. Open the notebook in VS Code.
4. Select your Python kernel.
5. Run all notebook cells.

## 📈 Results
Run the notebook to obtain the actual training results and test accuracy.
